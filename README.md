markdown# Professional Linktree Clone

A beautiful, professional link-sharing website with glassmorphism effects and animated gradients.

## 🚀 Quick Start

1. **Clone and Install**
   ```bash
   npx create-react-app my-linktree
   cd my-linktree
   npm install tailwindcss@latest

2. **Replace Files**

Copy all the provided code into the respective files
Update src/data/links.js with your information


Download Icons

Download SVG icons from Heroicons, Feather, or Lucide
Place them in src/assets/icons/ folder


Run Development Server
bashnpm start

Deploy to Vercel
bashnpm run build
# Then deploy the build folder to Vercel
