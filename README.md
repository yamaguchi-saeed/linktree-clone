# Professional Link Hub

A beautiful, modern link-sharing website featuring glassmorphism effects, animated gradients, and a fully responsive design. Built with React and Tailwind CSS for optimal performance and easy customization.

## ✨ Live Demo
[View Live Site](https://linktree-clone-topaz.vercel.app/)

## 🎨 Features
- **Glassmorphism Design** - Modern frosted glass aesthetic
- **Animated Gradients** - Dynamic, color-shifting backgrounds
- **Fully Responsive** - Perfect on mobile, tablet, and desktop
- **Theme Variants** - Multiple color schemes available
- **Modular Architecture** - Clean, reusable components
- **Fast & Lightweight** - Optimized for performance
- **Easy Customization** - Simple configuration file

## 🛠️ Tech Stack
- React
- Tailwind CSS
- Modern CSS Animations
- Modular Component Architecture

## 🚀 Want to Build Your Own?

If you'd like to create your own version of this link hub, here's how:

### Quick Setup
```bash
# Create a new React app
npx create-react-app my-linktree
cd my-linktree

# Install Tailwind CSS
npm install tailwindcss@latest

# Copy the code structure from this repo
# Update src/data/links.js with your information
```

### Customization Guide

**Update Your Profile**
Edit `src/data/links.js` with your name, bio, and social links.

**Change Color Themes**
Modify the gradient classes in `src/App.css` to match your brand.

**Add/Remove Links**
Simply add or remove objects from the `linksData` array.

**Download Icons**
Get free SVG icons from [Heroicons](https://heroicons.com), [Feather](https://feathericons.com), or [Lucide](https://lucide.dev) and place them in `src/assets/icons/`.

### Deployment
```bash
npm run build
```
Then deploy the `build` folder to [Vercel](https://vercel.com), [Netlify](https://netlify.com), or your hosting provider of choice.
